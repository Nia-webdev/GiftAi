# GiftAI 🎁

## AI-Based Personalized Gift & Delivery Management System

GiftAI is a web-based Final Year Project (FYP) designed to help users explore gifts and discover personalized gift recommendations for different occasions.

## Features

- Browse gifts by category
- Explore personalized gift recommendations
- Manage gift orders
- User-friendly and responsive interface
- Gift delivery management

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
- React Router

## Project Status

Currently under development as a Final Year Project (FYP).
